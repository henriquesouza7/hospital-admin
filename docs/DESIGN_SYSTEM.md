# Direção de Design

Ainda não é um design system final.

## Objetivo visual
Interface administrativa limpa, moderna, profissional e densa o suficiente para operação diária.

## Prioridades
- Legibilidade
- Hierarquia clara
- Navegação rápida
- Tabelas e filtros eficientes
- Estados de loading, vazio e erro
- Responsividade
- Acessibilidade

## Componentes previstos
- App shell
- Sidebar
- Page header
- KPI card
- Data table
- Filters
- Search
- Date/period picker
- Form fields
- Status badge
- Dialog
- Alert
- Empty state
- Skeleton
- Charts

## Restrições
- Evitar aparência de landing page.
- Evitar excesso de gradientes, sombras e animações.
- Não usar cores como única forma de comunicar status.
- Design deve priorizar desktop, mantendo responsividade.
