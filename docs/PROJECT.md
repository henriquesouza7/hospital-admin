# Visão do Projeto

## Problema
Controles administrativos do hospital estão distribuídos em planilhas mantidas por diferentes pessoas. Isso dificulta consolidação, histórico, comparação e geração de indicadores.

## Objetivo
Criar uma aplicação web interna para centralizar lançamentos administrativos, financeiros e de produção, convertendo dados operacionais em dashboards, métricas e comparativos.

## Usuário inicial
Um único operador administrativo alimentará e controlará o sistema no MVP. A arquitetura deve permitir múltiplos usuários e permissões no futuro.

## Fora do escopo inicial
- Prontuário eletrônico.
- Prescrição.
- Registros clínicos detalhados.
- Substituição de sistemas oficiais do SUS.
- Integrações hospitalares complexas.

## Módulos
1. Financeiro
2. Internações Hospitalares
3. Produção Hospitalar
4. Pequenas Cirurgias
5. Dashboard Geral
