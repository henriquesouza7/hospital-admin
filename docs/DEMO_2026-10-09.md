## Preparação local segura

1. No worktree isolado `hospital-admin-consolidacao-final`, use
   `pnpm install --frozen-lockfile`.
2. Configure `.env.local` somente nesse worktree, usando o branch Neon com ID
   `br-misty-recipe-b8muzwtd`, projeto `floral-breeze-18394345` e banco
   `neondb`. Os endpoints foram obtidos da configuração oficial Neon Auth e
   Data API desse branch; não copie variáveis do checkout antigo nem de
   production. Gere localmente `NEON_AUTH_COOKIE_SECRET` com pelo menos 32
   caracteres. Não grave nenhum valor de ambiente no Git ou neste documento.
3. Execute `pnpm dev`. Na validação atual, a porta 3000 já estava ocupada, então
   Next iniciou em `http://localhost:3001`; a porta usada deve ser confirmada
   antes da apresentação. O Neon Auth do branch permite localhost.
4. Entre pelo formulário oficial em `/login` usando a conta admin já existente.
   Não recrie a conta nem altere sua permissão. Não compartilhe senha, cookie ou
   token no chat.
