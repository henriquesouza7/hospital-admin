## Preparação local segura

1. No branch `feat/consolidacao-final-demo`, use `pnpm install --frozen-lockfile`.
2. Crie `.env.local` somente neste worktree a partir de `docs/NEON_SETUP.md`.
   Preencha `NEON_AUTH_BASE_URL` e `NEON_DATA_API_URL` copiadas do branch Neon
   de demonstração confirmado por ID no console; gere um
   `NEON_AUTH_COOKIE_SECRET` local com ao menos 32 caracteres. Não copie
   variáveis de production e não salve valores no Git ou neste documento.
3. Inicie com `pnpm dev` e acesse `http://localhost:3000`. O app não estará
   utilizável até que as URLs correspondam ao projeto e branch de demonstração
   e exista um administrador provisionado no Neon Auth oficial.
4. A autenticação deve ser concluída pelo fluxo legítimo do Neon Auth. A conta
   deve receber o papel `admin` pelo mecanismo oficial previsto no projeto.
   Não compartilhe senha, cookie ou token no chat.
